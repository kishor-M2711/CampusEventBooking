# Campus Event Booking System

A fresh beginner-friendly Java Swing project on the campus event topic.

## Features
- View campus events
- Add a new event
- Book a seat for a student
- View all bookings
- Cancel a selected booking
- Simple dashboard counts
- Separate Java files for each class

## Requirements
- JDK 17 or later
- VS Code or any Java IDE

## Run from the project folder
```bash
javac -d out src/main/java/campusbooking/*.java
java -cp out campusbooking.Main
```

Event and booking records are kept in memory while the application is running. This keeps the example focused on basic Java classes, objects, ArrayLists, Swing components and event handling.
